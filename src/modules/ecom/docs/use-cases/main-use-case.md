# E-Commerce System Use Case Diagram

## Actors

- Customer
- Admin
- Employee

---

## Customer Use Cases

- Browse products
- Search / filter products
- View product details
- Manage cart
- Place order (COD)
- Provide delivery info

---

## Admin Use Cases

- Manage products
- Manage categories
- Manage inventory
- Manage orders
- Assign orders to employees
- Manage users
- Manage pricing / discounts
- View analytics
- Configure delivery rules
- Handle refunds/issues

---

## Employee Use Cases

- View assigned orders
- Confirm order details
- Update order status
- Contact customer
- Report issues
- Handle COD payments
- Manage returns / failed deliveries
