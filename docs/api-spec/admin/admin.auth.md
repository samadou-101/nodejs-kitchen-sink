# Admin Auth API

## POST /admin/register

**URL:** http://localhost:3000/api/ecom/admin/register

```json
{
  "email": "admin@example.com",
  "name": "Admin Name",
  "password": "securepassword123"
}
```

## GET /admin/login

**URL:** http://localhost:3000/api/ecom/admin/login

```json
{
  "email": "admin@example.com",
  "password": "securepassword123"
}
```
